# الطالب الصامد — نسخة Local-first

تتضمن هذه الحزمة:
- تسجيلًا محليًا خفيفًا وتحديد الصف والمادتين.
- Dashboard للبرنامج السنوي في الفيزياء والكيمياء.
- نسخة PWA قابلة للتثبيت والعمل دون اتصال بعد تحميل الوحدة.
- ZIP مستقل لوحدة الزخم يعمل بفتح `unit.html` مباشرة.

## تشغيل Streamlit
```bash
pip install -r requirements.txt
streamlit run app.py
```

## ملاحظة PWA
يلزم فتح مسار PWA مرة واحدة عبر HTTPS أو localhost لتسجيل Service Worker. أما ZIP الخاص بالوحدة فيعمل مباشرة من القرص دون خادم.


## المسار العلاجي من ثلاث مراحل

لكل وحدة متاحة مسار واضح يناسب من انقطع عن الدراسة أو يحتاج إلى ترميم المفاهيم:

1. **مراجعة الدرس:** شرح المفهوم والعلاقة كاملة، ثم يضع الطالب القيم في التعويض العددي.
2. **حل تمارين الكتاب:** تطبيق مرتب على أسئلة الكتاب دون القفز إلى النتيجة.
3. **تمارين إضافية:** تدريب جديد لتثبيت الفهم وقياس الاستقلالية.

تُحمَّل المراحل الثلاث معًا داخل حزمة الوحدة وتعمل دون اتصال.

## محرك المراجعة الاحترافي

أعيد بناء المرحلة الأولى كمحرك درس مستقل، وليس نسخة من واجهة التمارين. وتتضمن الآن:

- خريطة مفاهيم: **7 دروس للفيزياء** و**8 دروس للكيمياء**.
- موقفًا حياتيًا وتمهيدًا مبسطًا وهدفًا واضحًا لكل درس.
- شرحًا قصيرًا وتمثيلًا بصريًا وبطاقة علاقة كاملة وقاموسًا للرموز والوحدات.
- مثالًا موجّهًا يعرض العلاقة كاملة ويترك للطالب التعويض العددي والحساب.
- سؤال «توقف وفكر»، وبطاقة ذاكرة، وتنبيهًا إلى الخطأ الشائع.
- عدم كشف خطوات الحل المكتملة إلا بعد مشاركة الطالب.
- محركًا مطابقًا في PWA يعمل دون اتصال، مع تقدم مستقل للمراجعة.


## المدخل التأسيسي للسنوات السابقة

تبدأ الوحدة الأولى في الفيزياء والكيمياء بمرحلة تأسيسية مستقلة من مفاهيم الصفين العاشر والحادي عشر، ثم مراجعة الوحدة الحالية، ثم تمارين الكتاب، ثم التدريب الإضافي. يشمل تأسيس الفيزياء الوحدات والمتجهات والحركة وقوانين نيوتن والطاقة، ويشمل تأسيس الكيمياء بنية الذرة والجسيمات والنظائر والأيونات والأغلفة وإلكترونات التكافؤ. تعمل المرحلة دون اتصال بعد تحميل الوحدة، وخطوط الشرح والحقول مكبرة بوضوح.


## تبسيط علاجي إضافي v12

- الفكرة الأساسية في جملة واحدة قبل الشرح.
- استعمال الأسهم لتمثيل اتجاهات الكميات المتجهة في الفيزياء.
- عرض العلاقة كاملة بالرموز أولًا.
- تعويض الطالب مباشرة داخل فراغات مدمجة في سطر المعادلة، لا في خانات منفصلة.
- عدم كشف القيم أو الحل قبل مشاركة الطالب.

## التصميم النهائي للمنصة v13
- لوحة طالب RTL مستوحاة من نموذج Figma المرفق: هيدر هادئ، Hero زيتي/زمردي، مؤشر إنجاز أصفر، وإحصاءات سريعة.
- مسار أفقي من أربع مراحل يتسع فيه العنصر النشط تلقائيًا.
- الوحدات تعرض كبطاقات مطوية مع وسوم حالة ومؤشر دائري صغير.
- اعتماد نظام بصري موحد على صفحات التأسيس والمراجعة وتمارين الكتاب والتدريب.
- جميع الأنماط محلية بلا Tailwind CDN حتى يبقى التشغيل دون اتصال حقيقيًا.

## إصلاح واجهة Streamlit v14
- أصبحت لوحة الطالب مكوّنًا محليًا معزولًا داخل Streamlit بدل تركيبها عبر كتل Markdown وأعمدة منفصلة.
- هذا يمنع ظهور الشريط الأبيض الفارغ وانفصال بطاقات المسار والفراغ الكبير قبل الوحدات.
- الهيدر والـHero والمسار والوحدات تُرسم الآن داخل بنية واحدة مطابقة للمعاينة، مع استجابة فعلية للهاتف.
- أزرار الانتقال والإعدادات وتنزيل حزم ZIP مرتبطة بالمنصة من داخل المكوّن.
- أضيفت لقطتا تحقق فعليتان في مجلد `previews` لسطح المكتب والهاتف.

## ثبات الصفحة وتجربة الاستخدام v15
- أُصلحت حلقة زيادة ارتفاع iframe التي كانت تجعل الصفحة تهبط باستمرار؛ أصبح الارتفاع محسوبًا من نهاية المحتوى الفعلية ويستقر بعد رسالة واحدة.
- أضيف شريط وصول سريع لمتابعة التعلّم أو الانتقال مباشرة إلى المسار والوحدات ومعلومات المنصة.
- كُبّرت الخطوط والمسافات وحُسّنت البطاقات والترتيب البصري لسهولة الاستخدام على الحاسوب والهاتف.
- أضيف Footer احترافي يعرض رسالة المنصة والروابط السريعة ومعلومات الصف والمسار والخصوصية والعمل دون اتصال.
- يتضمن مجلد `previews` لقطات v15 من محاكاة فعلية لسلوك ارتفاع Streamlit على سطح المكتب والهاتف.
